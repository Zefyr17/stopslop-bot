# Исправление проблемы с кнопками голосования

## Проблема

После добавления функции `week close` для отдельных пар каналов, кнопки голосования перестали появляться в monitored каналах.

### Причина

В базе данных остались старые **глобальные активные недели** (`monitoredChannelId = null`), которые конфликтуют с новыми неделями, привязанными к конкретным каналам.

## Решение

### Шаг 1: Запустить скрипт для закрытия старых глобальных недель

```bash
node fix_old_weeks.js
```

Этот скрипт:
- Найдет все активные недели с `monitoredChannelId = null`
- Закроет их (установит статус `CLOSED`)
- Покажет текущие активные недели

### Шаг 2: Перезапустить бота

```bash
npm run dev
```

### Шаг 3: Проверить работу

1. Отправьте ссылку в monitored канал
2. Убедитесь, что появились кнопки голосования "Yes (0)" и "No (0)"
3. Проверьте логи в консоли:
   ```
   Using active week [WEEK_ID] (monitoredChannelId: [CHANNEL_ID]) for channel [CHANNEL_ID]
   Created post [POST_ID] for link: [LINK]
   Post created in week [WEEK_ID] for channel [CHANNEL_ID]
   Added voting buttons to message: [MESSAGE_ID]
   ```

## Что было изменено

### 1. Добавлено логирование в `src/services/PostService.ts`
- Логируется ID активной недели и канала при создании поста

### 2. Добавлено логирование в `src/bot.ts`
- Логируется информация о созданном посте и недели

### 3. Создан скрипт `fix_old_weeks.js`
- Закрывает старые глобальные активные недели

## Техническая информация

### Как работает система недель теперь:

- **До изменений**: Одна глобальная неделя для всего сервера
- **После изменений**: Отдельная неделя для каждой пары каналов (monitored → shortlist)

### Схема базы данных:

```prisma
model Week {
  id                 String     @id @default(cuid())
  monitoredChannelId String?    // Новое поле!
  startDate          DateTime
  endDate            DateTime
  status             WeekStatus @default(ACTIVE)
  posts              Post[]

  @@unique([monitoredChannelId, startDate])
}
```

### Команды для работы с неделями:

```bash
# Закрыть неделю для всех каналов (старый способ)
/week close

# Закрыть неделю для конкретного канала (новый способ)
/week close monitored:#channel-name
```

## Профилактика

В будущем, если вы добавляете новую пару каналов после того, как у вас уже были активные недели, рекомендуется:

1. Закрыть все старые глобальные недели командой `/week close`
2. Или запустить скрипт `fix_old_weeks.js`

## Дополнительная диагностика

Если проблема сохраняется, проверьте:

```bash
# Посмотреть все активные недели
node check_weeks.js

# Посмотреть логи бота
# Должны видеть строки с "Using active week..." при создании постов
```
